ABOUT THE ARCHIVE

關於臺灣神秘傳說地圖

這是一個以地點為入口的臺灣宗教與神秘傳說索引，收錄有公開來源的地方故事，並非完整的民俗資料庫。

來源可查僅代表傳說或信仰的記載、流傳有資料可參考，不代表神蹟、靈異或超自然情節已被客觀證實。

地圖標記採公共地標或區域近似位置，請勿據此闖入私人土地、禁區或危險場所。

資料日期不等同來源最後更新時間；如有錯誤，請至 GitHub 儲存庫提出修正建議。
