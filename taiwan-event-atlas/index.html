ABOUT THE ARCHIVE

關於臺灣事件地圖

這是一個以地點為入口的公共事件與民間故事索引。第一版為人工挑選的少量範例，未涵蓋臺灣所有重大案件。

已查證事件以公部門報告、法院／檢方資料或可信媒體報導為依據；都市傳說僅代表「此傳聞確實流傳」，不表示超自然情節屬實。

地圖標記採地標或區域近似位置，請勿將它視為事故精確座標。避免獵奇、騷擾當事人、造訪非公開場所或模仿危險行為。

資料日期不等同來源最後更新時間；如有錯誤，請至 GitHub 儲存庫提出修正建議。
