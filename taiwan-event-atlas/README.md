# 臺灣事件地圖 / Taiwan Event Atlas

繁體中文、手機優先的靜態事件地圖。以互動地圖瀏覽臺灣的重大交通事故、社會案件、公共災害與都市傳說。

## 資料庫版本（2026-11-23）
- 共 **40 筆**，原有 10 筆，本次新增 30 筆；涵蓋 17 個縣市（含金門及澎湖）。
- 四類：交通事故 11 筆、社會案件 5 筆、公共災害 17 筆、都市傳說 7 筆。
- 事件參考來源以中央社、國家運輸安全調查委員會、監察院、原民會、文化部文化記憶庫及地方觀光單位優先；已查證的是事件或傳聞的存在，不表示每個版本的細節均為定論。
- 記錄屬人工編輯的代表案例，並非完整、即時或具統計代表性的臺灣事件資料集。
- 只有精確日期可查證時才填入 YYYY-MM-DD；傳說時間不明使用 null，不以 1 月 1 日等虛構日期填補。
- 本版新增案例各自於 `events.js` 保留來源連結；舊資料來源仍應定期進行連結存活與說法再校對。

## 2026-11-23｜手動立即擴充

## 特色
- Leaflet + OpenStreetMap；可縮放、選取事件、回到臺灣全圖
- 分類、關鍵字、縣市、年份與排序篩選；隨機探索、深層連結
- 每筆事件附來源連結，區分「來源可查」與「民間傳說」
- 手機版清單與地圖；不需要金鑰、資料庫、打包或後端

## 編輯與倫理原則
- 事件已公開並有可核對來源，不等於已取得所有法律或行政細節。
- **都市傳說只證明傳聞流傳，不代表其內容真實。**
- 地圖標記僅為地標、車站或區域**概略位置**；不作為導航、精確定位或安全判斷。
- 不公布私人住址、受害者資訊或未經證實的指控；避免驚悚及煽動性描述。
- 部分早期報導傷亡數字後續可能修正；本版摘要不列即時或未核實的傷亡統計。
- 如需新增資料，先補正來源、核對座標與分類，再編輯 `events.js`。

## 本機開啟
`python -m http.server 8000`，瀏覽 `http://localhost:8000/taiwan-event-atlas/`。
驗證：`node --test taiwan-event-atlas/tests/validate.cjs`。
外部網路需可存取 Leaflet CDN 與 OpenStreetMap 地圖圖磚。

## 設計來源
以使用者的 Notion 第二大腦「常用輸出與設計偏好」與「實用線上工具｜15 個網站速查索引」為參考：重視資訊層級、簡化流程、手機可讀性。保留原創視覺，不直接複製他站素材。

資料來源逐筆列於 `events.js` 中。
