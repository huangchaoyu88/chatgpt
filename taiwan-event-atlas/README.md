# 臺灣神秘傳說地圖 / Taiwan Mystery & Folklore Atlas

以 Leaflet 與 OpenStreetMap 呈現臺灣的宗教信仰、靈異傳聞、神秘事件、鄉野傳奇與神仙志怪。網站沿用原本地圖操作、篩選與分享功能。

## 2026-11-24 主題轉型

依專案需求，從目前展示資料中移除交通事故、社會案件及公共災害，只保留原先具有公開來源的 **7 筆**民間故事，重新分配到五種主題。未為了填滿分類而編造新故事；目前「神秘事件」類別可為空，等待後續查核新增。舊資料可透過 Git 歷史版本追溯，但不再由目前的 `events.js` 提供。

## 資料規範

- 宗教信仰、靈異傳聞、神秘事件、鄉野傳奇、神仙志怪五類。
- 來源只證明故事或信仰的記載與流傳，**不表示超自然現象已獲客觀證實**。
- 日期未知填 `date: null`；不虛構精確日期。
- 地圖座標為概略位置，不能用來尋找私人住址、闖入禁區或冒險探訪。
- 每筆保留來源連結、地區、精度說明及約 150 字的繁體中文敘述。
