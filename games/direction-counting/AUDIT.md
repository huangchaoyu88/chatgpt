# 方向尋寶遊戲：缺點盤點與修正

盤點範圍：小學一年級學生在手機上練習「左、右、上、下」的視覺辨識、從指定邊起數，以及逐步獨立作答。優先級代表對這個使用情境的影響；P0 最高，P5 最低。

## P0：遊戲無法開始或主要流程中斷

本次未發現會讓網站無法載入、題目無法作答或關卡無法完成的 P0 缺陷。

## P1：教學正確性與方向理解

| 缺點 | 修正 |
| --- | --- |
| 部分動態文字在關卡切換、回饋或結算時沒有注音。 | 所有畫面文字改用同一套注音標記；補齊動態遊戲文字的字音資料，並處理常見多音詞。 |
| 「寶藏」的「藏」音不正確。 | 改用此詞的正確讀音，並補上詞組讀音覆蓋。 |
| 提示需連續答錯才會解鎖，而且只重複指出起點，沒有示範數法。 | 「一起數」隨時可用；逐隻高亮起點到目標，並同步播放數字語音。 |
| 隨機題目可能讓某個方向練習不足；目標若在正中間，左右或上下起數會得到相同答案，無法辨識起點觀念。 | 每局固定左右、上下各 5 題；前兩關先用相同隊伍比較相反起點；目標避免放在正中央。 |
| 箭頭、起點旗標和上下端標記缺少一致的方向提示。 | 加大方向提示並用顏色、箭頭、端點標籤和起點旗標共同表示。 |

## P2：手機操作、語音和進度恢復

| 缺點 | 修正 |
| --- | --- |
| 關卡進度條曾以已得星星計算，與「完成題目」標籤不符。 | 改為顯示完成題數；星星仍獨立記錄答對表現。 |
| Edge TTS 載入失敗時缺少明確的重播入口；快速切題或離開頁面可能留下過期音訊。 | 加入再聽一次按鈕、備用語音及播放逾時處理；切題、暫停和頁面離開會取消舊語音與數數動畫。 |
| 回首頁後容易失去目前關卡，重新開始也可能誤觸。 | 自動保存目前進度；提供繼續遊戲和重新開始確認。 |
| 手機窄螢幕上的垂直排列、點擊區和動態效果容易造成辨識或操作困難。 | 放大注音和按鈕、調整上下題版配置，並支援減少動態效果設定。 |

## P3：學習結果資訊

目前有全局與四方向的「自己一次答對」統計。後續可加入各方向的答題次數變化，讓家長更清楚看到練習進步。

## P4：長期使用與資料管理

目前進度保存在此裝置的瀏覽器，不會跨裝置同步。若未來需要家庭或班級長期使用，可加入多名學生檔案、跨裝置同步與匯出功能。

## P5：內容延伸

可在核心方向辨識熟練後，再增加更多圖像主題、可選語速、角色造型與關卡獎勵。這些延伸不應蓋過方向、起點和數數三項學習目標。

## 驗證

- Node 自動測試：題目分配、四方向配額、答題邏輯、進度狀態與儲存資料驗證。
- 靜態檢查：瀏覽器程式、遊戲邏輯和音訊程式語法。
- 發佈流程：在 GitHub Actions 產生 Edge TTS 音檔，打包 Pages 靜態檔並部署。
